# Parenthesia

ウルティマ6/7風のRPGを作るための **コンストラクション（作成エンジン）**。
ゲーム単体ではなく、「ウルティマ風RPGを作れる土台」を目指す。

> 名前の由来: Scheme の括弧（parenthesis）+ 地名っぽい響き。

## コンセプト

- ウルティマ風RPG（見下ろし型・オープンワールド）を作れるエンジンとツール
- ゲームの中身（NPC、会話、日課、アイテム、イベント）は **Scheme で書く**
- 最初はテキスト／スクリプト中心。GUIエディタは後から、**Scheme で拡張・書き換え可能**な形で作る（Emacs / Smalltalk 的な発想）

## ウルティマ風の核になる要素

- キーワード会話（NPCに話題を振って情報を引き出す）
- NPCの日課（時間帯ごとに働き、食事し、寝る）
- オブジェクトの何でも操作（持つ、動かす、使う）
- 昼夜と天候がシームレスに変わる世界
- 行動に応じて変わるNPCの態度

## 技術方針

- **ランタイム**: Rust + Bevy
- **スクリプト**: 既存の組み込み Scheme で始める（第一候補は Steel。合わなければ s7 などに差し替え）
- 自作 Scheme 処理系（Kabos 構想）は後回し。ゲームが動いてから差し替える
- 別プロジェクトとして独立（glyphfall とは切り離す）

## 設計ルール

1. ゲームの操作は **すべて Scheme から呼べる API** に通す
2. ランタイム自身もその API を使う（内部だけの裏口を作らない）
3. データは Scheme（S式）で書く（NPC・日課・会話など）
4. Scheme は ECS を直接触らず、**コマンドをキューに積む**。システム側が毎フレーム処理する
5. スクリプトの **ホットリロード**を最初から入れる
6. 将来のGUIエディタは「その API を叩く Scheme プログラム」として作る

## ロードマップ

1. **最小の縦切りプロトタイプ**
   - Bevy の空ウィンドウに Scheme 処理系を組み込む
   - 1つのマップに、Scheme で定義した日課付き NPC を1人置く
   - 話しかけるとキーワード会話ができる
2. API の整理（NPC生成、移動、会話開始、アイテム操作など）
3. マップ・イベント・アイテムなど対象の拡大
4. GUI エディタ（だいぶ先。Scheme で書き換え可能に）
5. 自作 Scheme 処理系への差し替え検討
